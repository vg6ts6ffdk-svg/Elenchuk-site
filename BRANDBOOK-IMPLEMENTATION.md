# ROSEEN: применение согласованного брендбука 4.0

Основание: ROSEEN_Brandbook_4_0_Pages_Corrected.pdf, страницы 5–10, 15–18, 24. Пользователь согласовал документ в чате 20.09.2026. PDF — растровая копия для просмотра, поэтому изображения из него не трассируются. Геометрия сохранена из векторных мастеров ROSEEN_Brand_Kit_FINAL.zip; ширина английского слова 1843.5385 u, русского 1561.1709 u, H=200 u соответствует размерным листам. SHA-256 исходников и web-экспортов: assets/brand/manifest.json.

## Применение
- Все публичные страницы с site-header получают общий brand.css на этапе сборки. В dist находятся обычные статические HTML; клиентский JS не меняет логотип.
- Шапка: английский wordmark без нечитаемого дескриптора, 200 px desktop / 160 px mobile. Footer: русский wordmark. Favicon: исходная монограмма R.
- Основные цвета #0F172A, #3B82F6, #FFFFFF. Дополнительные UI-оттенки для границ и контрастного текста не перекрашивают мастер-логотип.
- Inter загружается с официального rsms.me; системный стек — только fallback. Шрифты не включены в бренд-кит.
- Размеры: h1 56/62, mobile 36/41 (32 на ширине до 360); h2 36/42; основной текст 16/25.
- RO → SE → EN: шаг 180 ms, общая длительность 720 ms. При reduced motion всё статично. Параллакс и смещение самой графики логотипа убраны.
- Сохранены страницы услуг, текущие изображения с подписью «иллюстрации», навигация, SEO-тексты и контракт формы /api/requests. База данных и авторизация не меняются.
- До публикации: node scripts/brand-qa.mjs; просмотреть screenshots из artifact brandbook-browser-review. HTTP Ready не заменяет проверку браузером.

## Граница проверки
Playwright проверяет сборку на 320/390/768/1440 px в Chromium и основные страницы 390 px в WebKit. Это эмуляция, не физический iPhone. Форма проверяется с перехваченными ответами; тест не доказывает доставку реальной заявки в production. Реальные клиентские заявки не отправляются.
