# ROSEEN — Robotics • Service • Engineering

Многостраничный адаптивный сайт сервисного центра.

## Что добавлено
- интерактивная 3-шаговая форма заявки;
- добавление фото / видео / PDF с браузерной проверкой размера;
- генерация готового текста заявки и копирование в буфер обмена;
- отдельные страницы: робототехника, электроника, бытовая техника, диагностика, ремонт, обслуживание, инженерная помощь;
- кинематографические scroll/reveal-анимации, parallax, cursor glow, magnetic CTA, 3D tilt карточки;
- мобильное меню;
- RAL 6018 как фирменный акцент (экранный RGB-эквивалент в CSS).

## Важно
Форма сейчас работает без внешнего backend: она валидирует данные в браузере и формирует готовую заявку для передачи в выбранный канал. Для автоматической отправки в Telegram/email потребуется подключить backend или webhook.
