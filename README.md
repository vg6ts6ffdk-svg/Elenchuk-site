# ROSEEN — service site v3 fixed

Исправленная версия сайта ROSEEN.

## Что исправлено
- Устранен критический CSS-конфликт, из-за которого `.orb` превращался из абсолютного декоративного элемента в обычный элемент потока и ломал мобильную верстку.
- Контент больше не исчезает при полной загрузке страницы, даже если IntersectionObserver еще не успел проиграть анимацию.
- Сохранены и усилены scroll/parallax/cinematic-анимации.
- Добавлен кинематографичный переход между отдельными страницами направлений.
- Сохранены интерактивная 3-шаговая форма заявки и отдельные страницы направлений.
- Фирменный цифровой цвет приведен к RAL 6018: #57A639 (экранное RGB-представление).
- Логотип и иллюстрации приведены к той же цветовой системе.
- Адаптивная мобильная навигация сохранена.

## Запуск
Откройте `index.html` в браузере или разместите содержимое архива на обычном статическом хостинге.
