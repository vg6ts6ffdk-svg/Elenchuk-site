# ROSEEN — v4 fixed

Адаптивный многостраничный сайт сервиса ROSEEN.

- `index.html` — главная
- `robotics.html` — робототехника
- `electronics.html` — электроника
- `appliances.html` — бытовая техника
- `diagnostika.html`, `remont.html`, `servis.html`, `engineering.html` — сервисные направления
- Все изображения для сайта лежат локально в `assets/`.
- Анимации работают без внешних библиотек.
- Форма заявки работает на клиентской стороне и не отправляет данные сторонним сервисам.
