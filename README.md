# Elenchuk Service Site

Персональный сайт Романа Еленьчука, адаптированный под инженерный сервис: диагностику и ремонт различной техники, электроники, профессионального оборудования и роботизированных систем.

## Страницы
- `index.html` — главная
- `services.html` — ремонт и диагностика
- `robots.html` — сложная техника и роботы
- `about.html` — о сервисе и подходе
- `contacts.html` — заявка на ремонт

Структура и анимации существующей версии сохранены; изменено позиционирование и содержимое.
