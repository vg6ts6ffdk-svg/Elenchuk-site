# ROSEEN — единый рабочий поток

Дата фиксации: 2 октября 2026.

## Единственный активный источник

**main** — единственная ветка, от которой продолжается разработка сайта ROSEEN.

Новые изменения по сайту, магазину, личному кабинету, новостям, бренду и CC1 должны исходить только из актуального main и возвращаться в main через проверяемый PR. Старые ветки не являются источником актуальных требований и не должны использоваться как база новой работы.

Актуальный main при фиксации: `7b9914406093c776378e2eeb02a970f27cb06434`.

## Что уже находится в main

- многостраничный сервисный сайт;
- утверждённая схема РОСИН в header / ROSEEN в footer / favicon R;
- брендовые motion-правила;
- read-only магазин, категории, поиск, фильтры и корзина;
- подготовка PUDU CC1 как первого реального каталога;
- Preview личного кабинета;
- безопасный dry-run импорт каталога;
- доменная модель и persistent repository заказов, не подключённые к публичному checkout;
- раздел «Новости» и еженедельные брифинги;
- изолированные CC1-прототипы, которые не выдаются за production-анимацию.

## Правило продолжения

1. Перед любой работой читать актуальный main.
2. Не продолжать старую feature/fix ветку.
3. Не возвращать старые варианты логотипов или дизайна из архивных веток.
4. Не удалять исторические материалы только ради «чистоты».
5. Если из архива понадобится конкретный фрагмент, переносить его осознанно поверх актуального main после проверки.
6. В пользовательской коммуникации считать эту работу одной веткой проекта «Сайт».
