Latest owner clarification: rear shell is lime, front shell is grey; remove rear then front, then internal assemblies; the two bottom motor wheels are removed near the end. The colour clarification and exact geometry still need comparison with the supplied real teardown material.

Known review gaps: prototype v2 has no robots meta, relies on an external image, uses inline CSS and global overflow masking, and its controller has no reduced-motion fallback. Preserving these experiments does not certify them as production-ready.
